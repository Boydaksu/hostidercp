# ADR-002 — F0.1 güvenlik sınırlarının netleştirilmesi

Durum: kullanıcı F0.1 inceleme talebine dayalı uygulama kararı; 2026-10-22. İş kuralları ve modüler monolit değişmez.

- `staff` yalnız personel/MFA niteliğidir. CustomerId eşleşmesi yalnız mevcut operation için güvenilir Identity servisinin verdiği explicit customer grant ile aşılabilir. Customer/service/department boyutları birlikte sınanır. `*` müşteri kapsamı ancak o işlem için explicit grant'te olabilir, staff/admin bayrağından türetilmez. Impersonation actor'ı korunur; admin yetkileri müşteri bağlamına taşınmaz, ayrı effective permission ve hedef kapsam gerekir. F1 bu principal'ları sunucu tarafından oluşturacak; request JSON'undan grant alınmaz.
- Queue dedupe canonical JSON üzerinden olur. Object anahtarı sıralaması anlamsızdır; list sırası, scalar türü ve object/list ayrımı anlamlıdır. Hassas/sayısal alanlar float içeremez. Mevcut idempotency fingerprint formatı korunur.
- Session snapshot dönerken native PHP kilidi kapanır; uygulama yazımı kısa `mutate` callback'inde fresh state + expected version ile yapılır. Rotation/logout eski SID'yi silmek yerine revoked/retired tombstone yazar; paralel eski request yeniden kimlik yaratamaz. Native file-session lock yerel tek hosting için uygundur; dağıtık session/revocation registry F1'dir. Hiçbir authenticated mutation yalnız uzun süre önce alınmış snapshot'a güvenemez.
- Audit genişletilmiş sabit event sözlüğü kullanır; parola/e-posta/token/IP/raw error kabul etmez. Başarısız auth için actor `anonymous`, subject opaque attempt reference olur. Identity olayının DB yazımı + audit aynı transaction; başarısız transaction audit'i de geri alır. Bağımsız güvenlik reddi için ayrı transaction üst seviye sorumluluğudur.
- Production mock dispatch ve mock result kabulü yasaktır; provenance sahte SUCCESS'in gerçek hizmet durumuna çevrilmesini engeller. Tüm canlı adapter GATE'leri açık; production hiçbir provider action çalıştıramaz.
- Retention süreleri ticari/yasal saklama kuralı değildir: rate-limit expiry algoritmik pencere sonudur; iş payload temizliği opt-in teknik housekeeping, dedupe fingerprint/attempt/trace korunur. FAILED/UNKNOWN/audit/outbox/inbox/idempotency otomatik silinmez. Yasal retention G-O04'tedir.
