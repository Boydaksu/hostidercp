# Kullanıcı tarafından sağlanan referans SDK

`voyar-api-client-user-provided.zip` önceki sohbet aşamasında kullanıcı tarafından sağlanan PHP Voyar istemcisinin byte-for-byte kopyasıdır. Geliştirici paketindeki teknik sözleşmeler bu SDK'nın `README.md`, `docs/` ve `src/` dosyalarını inceleyerek oluşturulmuştur.

Bu, SDK'nın güvenlik ve canlı API davranışlarının tam olarak doğrulandığı veya üretime çıkmaya hazır olduğu anlamına gelmez. Entegrasyondan önce kod incelemesi, test ve `docs/14_OPEN_VALIDATIONS.md` doğrulama kapıları zorunludur.
